# Business Blog Card

A clean and fully responsive business card design. It is a challenge from [devchallenge.io](https://devchallenges.io/).

## Challenge
[**Business Blog Card**](https://devchallenges.io/challenge/business-blog-card) from DevChallenge.io

## Features

- Fully responsive design (Mobile, Tablet, and Desktop)
- Clean and minimal aesthetic
- Built with **HTML5** and **Tailwind CSS**



## Technologies Used

- HTML5
- Tailwind CSS
